# Legal go/no-go — StainlessSteel release

Every item must be green to publish an official source snapshot, compiled binary or update channel.

- [ ] Define the **verified legal copyright holder** and permanent contact.
- [ ] Confirm ownership of all first-party source, media, designs, fonts and agent contributions; store signed agreements.
- [ ] Have qualified software-IP counsel review **PolyForm Strict** under relevant jurisdictions and match it to the intended commercial/personal-use policy.
- [ ] Counsel decides whether the 2026 GitHub Terms of Service (public forks, AI training/AI Features, and Access Reciprocity) fit the privacy/IP strategy.
- [ ] Publish unchanged official PolyForm Strict 1.0.0 text, not a hand-edited derivative, and link its canonical URL.
- [ ] Approve `COPYRIGHT_AND_SCOPE.md`, `COMMERCIAL_AND_REDISTRIBUTION.md` and actual legal contact details.
- [ ] Establish a compliant way for contributors to get **written modification permission** and sign an agreement before PR code acceptance.
- [ ] Generate `Cargo.lock`; pin all dependencies, Git revisions, platform-specific features and native bindings.
- [ ] Generate source, Rust, binary, assets, font, model and installer **SBOM** and full third-party license/NOTICE texts.
- [ ] Audit every distributable for GPL/AGPL/strong-copyleft conflicts; no unknown license; no Tare; no RTK BUSL engine.
- [ ] Audit historically mixed-license components (MCP) at precise git revision and document notices.
- [ ] Confirm OFL font naming/reserved names, package and source distributions.
- [ ] Ensure distro/Homebrew/third-party update mirrors do not redistribute StainlessSteel unless authorized by the copyright holder.
- [ ] Restrict official release artifact publication to maintainers; verify provenance/signatures and repackage policy.
- [ ] Clearly state on README and download page: **source-available, not open source**; don't advertise GPL rights.
- [ ] Prepare actual trademark/brand policy separately from copyright licensing.
- [ ] Have counsel review privacy, third-party provider SDK terms, service-specific API terms, and update installer notices.
- [ ] Recheck legal compatibility on **every new release** and for every new plugin or bundled agent.

Release must be blocked if any of the above remains unresolved. This checklist reflects intended policy, not an assertion that StainlessSteel currently passes.
