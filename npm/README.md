# stainlesssteel (npm)

Installs the prebuilt StainlessSteel binary for your platform and runs it.
Works with npm, bun, pnpm, and yarn — they all consume this same package.

```sh
npm install -g stainlesssteel
# or: bun add -g stainlesssteel
# or: pnpm add -g stainlesssteel
# or: yarn global add stainlesssteel
stainless doctor
```
